# 🕹️ Arcade // Anuraag Rao Virtual Arcadia

Unified game portal and experimental arcade launcher for web games engineered by [Anuraag Rao](https://anuraaggrao.com).

Live at: **[arcade.anuraaggrao.com](https://arcade.anuraaggrao.com)**

---

## Featured Games

1. **[Companion Protocol](https://companion.anuraaggrao.com)**
   - Edge protocol survivor roguelite featuring mortal human operators and immortal guardian familiars.
   - [Source Code](https://github.com/AnuraagGRao/companion-protocol)

2. **[Orbit Drift](https://orbit.anuraaggrao.com)**
   - Relativistic N-body deep space trajectory simulator with 320-step predictive aiming and procedural seed generator.
   - [Source Code](https://github.com/AnuraagGRao/orbital-gravity)

3. **[Tetra Overflow Ultra](https://tetra.anuraaggrao.com)**
   - Mobile-first arcade puzzle engine featuring touch drag/flick gestures, progressive Zodiac level challenges, and time-dilation Zone mechanics.
   - [Source Code](https://github.com/AnuraagGRao/tetra-overflow)

---

## Tech Stack

- **Visuals**: Modern Vanilla CSS, glassmorphism, dynamic responsive grid, CRT scanlines.
- **Audio DSP**: Real-time Web Audio Synthesizer for UI coin chimes and navigation blips.
- **Canvas**: Parallax starfield particle engine running at native 60+ FPS.
- **Hosting**: GitHub Pages + Cloudflare Custom Domain (`arcade.anuraaggrao.com`).
